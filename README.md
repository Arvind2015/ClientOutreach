# Client Outreach Agent

KYC remediation outreach automation — identifies missing/expired client KYC
requirements, drafts and sends outreach emails, and analyzes customer replies
(including document attachments), with a human-in-the-loop approval layer for
non-standard or high-risk cases.

## Repo structure

- `spec.md` — business-facing specification (problem statement, scope,
  functional/non-functional requirements, data entities, assumptions).
- `team-task-breakdown.md` — high-level task split across the build team.
- `.kiro/specs/client-outreach-agent/` — Kiro's native spec input:
  - `requirements.md` — EARS-format acceptance criteria
  - `design.md` — architecture and component design
  - `tasks.md` — implementation task checklist
